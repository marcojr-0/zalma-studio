# Zalma Studio Fitness

Site institucional desenvolvido para a academia **Zalma Studio Fitness**.

## Sobre o projeto

Este projeto apresenta as principais informações da academia, como modalidades, horários de funcionamento, localização e formas de contato.

O site foi feito com foco em um visual moderno, responsivo e alinhado à identidade da Zalma Studio Fitness, usando as cores preto, verde neon e branco.

## Funcionalidades

- Página inicial com chamada principal
- Foto do studio
- Seção sobre a academia
- Lista de modalidades
- Horários de funcionamento
- Localização com botão para Google Maps
- Botão de matrícula via WhatsApp
- Link para Instagram
- Layout responsivo para computador e celular

## Tecnologias usadas

- Python
- Flask
- HTML
- CSS

## Como rodar o projeto

Primeiro, instale as dependências:

```bash
pip install -r requirements.txt
```

Depois execute o projeto:

```bash
python app.py
```

Ou, se estiver no Fedora/Linux:

```bash
python3 app.py
```

Acesse no navegador:

```text
http://127.0.0.1:5000
```
